# 🚀 Automação e Build de Software:

Bem-vindo(a) ao módulo de **Ferramentas de Build**! Este repositório faz parte do projeto de Atividade Extensionista (**AEX-EACH-00060-01-Dev-sistemas**) da Universidade de São Paulo (USP/EACH).

Sabemos que a internet está cheia de tutoriais e documentações densas. Nosso objetivo aqui é traduzir conceitos complexos para uma **linguagem simples, direta e acessível**. Queremos que você pare de digitar comandos longos e repetitivos no terminal e aprenda a automatizar seus projetos como os profissionais fazem no mercado de trabalho!

---

## 🤔 Por que aprender ferramentas de Build?

Quando estamos começando a programar, compilar e rodar um código com um ou dois arquivos é fácil. Mas e quando seu projeto cresce? Fazer tudo manualmente torna o processo lento e muito sujeito a erros (esquecer um arquivo, errar a ordem, etc). 

As ferramentas de automação que você vai aprender aqui servem para:
- **Compilar** dezenas (ou milhares) de arquivos com um único comando.
- **Gerenciar dependências** (baixar bibliotecas externas automaticamente).
- **Rodar testes** e gerar pacotes prontos para uso.

## 📖 Como usar este material?

Para aproveitar ao máximo o conteúdo, sugerimos o seguinte fluxo:
1. **Escolha uma trilha** na tabela acima.
2. **Leia o README da ferramenta escolhida** para entender o mapa das aulas.
3. **Siga a ordem das aulas** (começando pela Aula 00 de configuração).
4. **Coloque a mão na massa**: Não apenas leia! Digite os códigos, rode no seu computador e tente resolver os exercícios propostos nas pastas `exercicios/`.
5. **Acompanhe os Vídeos**: [Link para o canal do YouTube](https://m.youtube.com/@Reposit%C3%B3riodeSI).
